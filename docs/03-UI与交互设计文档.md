## 1. 视觉风格规范（高科技深色）

### 1.1 色板

| 用途 | 颜色 | Hex | 使用 |
|---|---|---|---|
| 背景底 | 深空蓝 | #0a0e17 | 页面背景 |
| 背景渐变 | — | #0a0e17 → #0d1526 | 径向/线性渐变 + 细网格（1px 线 rgba(0,229,255,0.04)，40px 网格） |
| 卡片底 | 玻璃蓝 | rgba(16, 24, 40, 0.72) | backdrop-blur 12px |
| 卡片边框 | — | rgba(0, 229, 255, 0.15) | 1px；hover 时 0.35 |
| 主色 | 霓虹青 | #00e5ff | 主数字、激活态、主线条 |
| 辅色 | 荧光绿 | #00ff9d | 在线状态、正常值、次线条 |
| 警告 | 琥珀 | #ffc53d | 黄色阈值 |
| 危险 | 告警红 | #ff3b5c | 红色阈值、离线 |
| 文字主 | — | #e6f1ff | 标题、主数字 |
| 文字次 | — | #8fa3c8 | 标签、辅助信息 |
| 文字弱 | — | #5a6b8c | 时间戳、占位 |
| 图表网格 | — | rgba(143, 163, 200, 0.12) | — |

### 1.2 字体

- 数字/数据：'JetBrains Mono', 'Roboto Mono', monospace（tabular-nums）
- 中文/UI：system-ui, 'PingFang SC', 'Microsoft YaHei'
- 层级：大数字 32px / KPI 24px / 正文 13px / 辅助 11px

### 1.3 效果与动效

| 效果 | 规格 |
|---|---|
| 卡片 | 玻璃拟态：rgba 底 + backdrop-blur(12px) + 1px 边框 + 圆角 10px；hover 边框提亮 + translateY(-1px) |
| 发光 | 主元素 box-shadow: 0 0 12px rgba(0,229,255,0.35)；红色告警: 0 0 16px rgba(255,59,92,0.5) |
| 状态点 | 8px 圆点；在线：绿色 + 脉冲（scale 1→1.6 opacity 1→0，1.5s infinite）；离线：红色实心 |
| 数字动画 | 数值变化：300ms count-up（rAF） |
| 图表 | ECharts animationDuration 300，areaStyle 渐变（主色 0.25→0），线条发光（shadowBlur 8） |
| 飘红脉冲 | danger 态：卡片边框 + 数字变红，边框发光 1.2s infinite 脉冲 |
| 扫描线 | 页面级细微扫描线（2px 渐变条，8s 循环，opacity 0.03）——可选，可关闭 |
| 事件流 | 新事件顶部滑入（200ms），自动滚动到底（若用户位于底部） |

### 2.2 HostCard 字段

| 区域 | 内容 | 数据源 |
|---|---|---|
| 顶部 | 状态点 + 主机名 + id | /api/hosts |
| 模型 | 模型名（短名）+ 参数量 | model.name / n_params |
| 速度 | gen_speed_tps 大数字 + 60s sparkline | gen_speed_tps + history |
| GPU | 每卡一条：利用率% + 显存% | gpus[] |
| 底部 | CPU% / MEM% / 磁盘% | cpu_pct / mem_pct |
| 告警 | 有 danger 告警时：红边框 + 右上角红色角标（数量） | alerts |

### 2.3 交互

- 卡片 hover：边框提亮、translateY(-2px)
- 点击：进入 /host/:id
- 刷新：WS /ws/portal 1s 推送
- 离线卡片：置灰 + 红色"离线"角标

### 3.2 TopBar

| 元素 | 说明 |
|---|---|
| 返回按钮 | ← 门户（router 回 /） |
| 主机标识 | name + 模型短名（basename，悬停 title 显示完整路径） |
| 核心指标芯片 | 单行紧凑数字芯片（空间不足时横向滚动）：速度（t/s，prompt 活跃时优先显示，tooltip 含 gen/prompt/来源）、MTP 接受率 %、上下文 剩余/总量（k）、每 GPU 利用率/温度/功耗/显存已用/总量、内存 已用/总量、CPU %；按 alerts 着色（warn 黄 / danger 红），无数据显示 — 置灰 |
| 状态徽章 | ● 在线（绿脉冲）/ llama 离线（红）/ SSH 断开（黄） |
| 刷新控制 | 下拉：实时（WS）/ 1s / 2s / 5s / 暂停；当前模式指示（WS 绿点 / 轮询黄点 / 暂停灰） |

### 3.3 AI 核心指标区（4 个 KpiCard）

| 卡片 | 主显示 | 辅助 | 数据（主/兜底） |
|---|---|---|---|
| Token 生成速度 | 大数字 tok/s（32px） | 60s sparkline；空闲显示 0.0 置灰；标注数据来源（log/API） | log.state.tg_3s_tps / llama.gen_speed_tps |
| Prompt 处理速度 | 大数字 tok/s | 60s sparkline；预填充中显示进度 % | log.state.prompt_speed_tps / llama.prompt_speed_tps |
| 上下文占用 | 环形 76.7% | 201047/262144 tokens + 剩余 61097；≥80 黄 ≥90 红 | log.context.* / slot.ctx_used |
| 任务状态 | ● 运行中/空闲 | 任务 #id、剩余 n_remain、已解码 n_decoded | log.state.* / slot.* |

### 3.4 llama 实时状态区（3 卡，回答"llama 当前在干嘛"）

- LlamaStateCard（当前状态）：
  - 阶段徽章：● Prompt 处理（进度条 + 进度 % + 速度）/ ● 生成中（已解码数 + 实时速度 tg_3s + 任务均值 tg）/ ○ 空闲
  - 任务 #id、is_child
  - 数据：log.state.*
- ContextCard（上下文占用）：
  - 大数字：已用/总量（pct%）+ 进度条（≥80 黄 ≥90 红）
  - 剩余 token、truncated 标志（truncated=是 显示红色"已截断"徽章）
  - 数据：log.context.*（日志 n_tokens 权威值）
- MtpCard（MTP 投机解码）：
  - 接受率大数字（pct，<80 黄 <65 红）+ accepted/generated 计数
  - 平均接受长度 mean len
  - 静态配置：spec_type（draft-mtp）× spec_draft_n_max（3）—— 来自命令行解析
  - 接受率趋势 sparkline（每任务一个点）
  - 数据：log.mtp.* + process.flags.spec_*

### 3.5 GPU 面板（每卡一个，GpuPanel）

| 区域 | 内容 | 阈值 |
|---|---|---|
| 头部 | GPU {index} · {name} + 状态点（util>0 绿脉冲 / 空闲灰） | — |
| 左侧 | 环形仪表：利用率 %（0-100） | ≥80 黄，≥90 红 |
| 右上 | 显存条：used/total GiB + % | ≥85 黄，≥95 红 |
| 右下 | 2×3 网格：温度 / 功耗（draw/limit）/ 风扇 / 图形频率 / 显存频率 / PCIe（gen x width · P-state） | 温度 ≥75 黄 ≥85 红；功耗 ≥85% 黄 ≥95% 红 |
| 底部 | 驱动版本 + 占用进程列表（pid name mem） | — |

### 3.6 系统区

- CpuPanel：整机 % 大数字 + 6 根竖条（每核，高度=利用率，颜色青→红渐变）+ load 1/5/15 + 主频；阈值 ≥80 黄 ≥90 红
- MemPanel：used/total 大数字 + 三条（used / buff_cache / available 堆叠）+ swap；阈值 ≥85 黄 ≥95 红
- DiskPanel：每挂载点一条（mount、used/total、%）+ 读写速率；阈值 ≥80 黄 ≥90 红
- NetPanel：每网卡 rx/tx 速率 + 60s 迷你曲线

### 3.7 进程区

- LlamaProcessCard：
  - 第一行：4 列指标网格（7 项，4+3 排布）：PID | 实时 CPU%（大数字）| 累计 CPU% | RSS | VSZ | 线程数 | 运行时长
  - 第二行：systemd 键值列表（标签左、值右，5 行）：服务 unit · active / 启动时间 / 服务级 CPU 累计 / 服务级内存（含峰值）/ Tasks
  - 命令行：等宽字体，默认展开（pre-wrap，可点击折叠）
  - 参数表：三列网格（参数名 → 值），20+ 项，可折叠（默认展开）
- TopProcessTable：两个表（Top CPU / Top 内存），各 8 行：pid name cpu% mem% rss（PID 与数值列右对齐，进程名超长省略号截断，悬停显示全名）

### 3.8 模型与 Slot 区

- ModelInfoCard：键值网格（名称/路径/ftype/参数量/文件体积/mmproj/嵌入维度/词表/上下文/模态/capabilities/owned_by）
- SlotTable：
  - 头部：Slot {id} · {运行中/空闲} · 任务 #{id_task}
  - prompt tokens：总 / 已处理 / 缓存（3 个数字）
  - 已解码 / 剩余 / 上下文占用条
  - 日志派生：prompt 进度（log）、任务耗时汇总（prompt/解码/总耗时与速度）、MTP 接受率、KV 保留 f_keep
  - 采样参数表（可折叠，默认显示 temperature/top_k/top_p/min_p/max_tokens/chat_format/speculative.types，全量 30+ 项可展开）

### 3.9 趋势区（TrendChart × 10）

| 图表 | 序列 | 类型 |
|---|---|---|
| Token 速度 | gen_speed（青）、prompt_speed（绿） | 折线 + 面积渐变 |
| GPU 利用率 | GPU0（青）、GPU1（绿） | 折线 |
| GPU 显存 | GPU0、GPU1（GiB） | 折线 |
| GPU 温度 | GPU0、GPU1（°C） | 折线 |
| GPU 功耗 | GPU0、GPU1（W） | 折线 |
| CPU | 整机（青） | 折线 + 面积 |
| 内存 | used（青）+ buff_cache（蓝，堆叠） | 堆叠面积 |
| 网络 | rx（青）、tx（绿） | 折线 |
| 上下文占用 | n_tokens（青，阶梯线）+ n_ctx 上限（红虚线参考线） | 阶梯线 + 参考线 |
| MTP 接受率 | 每任务接受率（绿，阶梯线，y 轴 0-100%） | 阶梯线 |

- 通用：窗口切换 5m/15m/1h（趋势区右上角全局切换）；y 轴自适应；tooltip 显示全部序列值 + 时间戳；断线时曲线断点（connectNulls: false）

### 3.10 事件流（EventFeed）

- 终端风格：等宽字体、深色底、级别标签着色 [INFO] 绿 / [WARN] 黄 / [ERROR] 红
- 事件来源：后端 EventDetector（以日志行为主）：任务开始（任务 ID/prompt token 数）、任务结束（总 token/耗时/平均速度/MTP 接受率/上下文占用）、启动（模型加载完成/boot 信息）、上下线
- 自动滚动：用户位于底部时跟随新事件；上滚后显示"↓ 新事件"按钮
- 保留 200 条，更早的淡出

## 7. 降级与空态

| 状态 | 展示 |
|---|---|
| llama 离线 | TopBar 红色徽章"llama 离线"；AI 核心区数字置灰显示最后值 + "数据截至 HH:MM:SS"；GPU/系统区正常（SSH 仍可用） |
| SSH 断开 | TopBar 黄色徽章"SSH 断开"；GPU/系统/进程区显示"数据不可用（SSH 断开）"占位（图标 + 文字），保留最后值置灰；AI 核心区正常 |
| 日志不可用（SSH 断开 / unit 名不符） | llama 实时状态区显示"日志不可用，使用 API 数据"置灰；速度回退 /slots 差分并标注数据来源 API |
| 两者都断 | 全页红色横幅"主机不可达"，所有区域占位 |
| 无 GPU | GPU 区显示"未检测到 NVIDIA GPU" |
| 单 GPU | GPU 区单卡占满整行 |
| 多 Slot | Slot 区每 slot 一张卡（网格） |
| 无进程 | 进程卡显示"未找到 llama-server 进程（可能以其他名称运行）" |
| 首次加载 | 骨架屏（卡片轮廓微光），WS 首帧到达后填充数据 |
